Help & system

How this demo works

Workflow

  • Choose a synthetic profile and one or more portals.
  • The local fixture parser ranks matches and returns the three newest for each selected portal.
  • Update a stage, save a bookmark or note, then create a fictional application draft.
  • Review and version drafts, or export your browser-local tracker.

Live source status

Use official portal pages directly. Live collection requires an authorized API or written permission.

Keyboard and navigation

Use the section tabs to move between Listings, Overview, Review, Profile, Tracker and Help. Press / from anywhere in the app to focus listing search, and ? to open Help.

Privacy & demo limits

Portal access: Disabled because the reviewed portal rules do not permit this demo to automate collection. The parser runs on fictional HTML fixtures.

Your tracker: Stages, bookmarks, packet drafts and notes stay in this browser's local storage. They are not sent to the API. Do not use shared devices for personal notes.

Visit alert: The server sends a minimal Telegram alert when the page is opened, at most once per 10-minute window. The alert contains no visitor name, IP address or page content. Website and API infrastructure may process ordinary request metadata in their logs.
